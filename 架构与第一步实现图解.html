Windows Tool Box · 总体架构 + 第一步实现
示意图：分层模块化架构 与「硬件检测 + 系统资源检测」数据流
A · 分层架构（从界面到内核）
① UI 展示层（WPF/WinUI）
硬件信息卡片 · 实时仪表盘 · 趋势曲线 · 进程/服务列表
↓
② 服务/调度层（核心）
硬件检测服务(低频) · 资源监控服务(1s 轮询) · 环形缓冲 · 通知/告警
↓
③ 采集适配层（多数据源封装）
WMI 查询 · 原生 API(P/Invoke) · 传感器库(LibreHardwareMonitor) · PDH 性能计数器
↓
④ 基础设施层（横切）
配置管理 · 日志 · 异常处理 · 权限提权 · 单例启动
B · 第一步数据流
阶段 1 · 硬件型号检测（启动时查询一次，可手动刷新）
触发：App 启动 / 手动刷新
→
采集：WMI / 注册表 / cpuid
→
建模：HardwareInfo 对象
→
UI 绑定显示
阶段 2 · 资源实时监控（后台线程每 1 秒轮询）
Timer(1s) 触发
→
采集快照（CPU/内存/磁盘/网络/GPU/进程）
→
ResourceSnapshot 入环形缓冲(60帧)
→
UI 更新仪表盘 + 趋势曲线
